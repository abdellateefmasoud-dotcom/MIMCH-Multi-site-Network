MIMCH Multi-Site Hospital Network

This repository contains the Cisco Packet Tracer project developed for the MIMCH multi-site hospital network.

The network connects three sites:

- Dubai
- Abu Dhabi
- Sharjah

The Packet Tracer file includes the network configuration, routing, VLANs, security, and connectivity implemented as part of the project.

Project File: "MIMCH-Multi-Site-Network.pkt"
